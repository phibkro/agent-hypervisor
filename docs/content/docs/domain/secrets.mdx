---
title: "Secrets"
description: "Agents use secrets by placeholder; the real value is swapped in only on the way out of the sandbox."
---

<BoundedContextDiagram name="Secrets" />

A secret is a reference into the owner's secret store, never the value. A session that holds a secret capability
sees a placeholder token; the egress proxy replaces it with the real value on requests to the destinations the
capability allows. The right is therefore a pair, a secret and a destination, which matches the HTTP scopes in
[capalg](/docs/capalg).

```mermaid
sequenceDiagram
  participant A as Agent (in sandbox)
  participant E as Egress proxy
  participant S as api.github.com
  A->>E: request with SECRET_GITHUB_7f3a
  E->>E: session holds (github token, api.github.com)?
  E->>S: request with the real token
  S-->>E: response
  E-->>A: response, token redacted
```
